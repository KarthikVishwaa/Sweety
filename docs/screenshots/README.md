# Screenshots

The main [README](../../README.md) links to these files. They are not committed yet: capture them from the running app and
save them in this folder with exactly these names.

Run the app with `npm run db:up`, `npm run db:migrate`, `npm run seed` and `npm run dev`, then log in as
`demo@sweety.app` / `Demo@1234` (see the README for details).

| File                            | What to capture                                                                     |
| ------------------------------- | ----------------------------------------------------------------------------------- |
| `01-login.png`                  | The login page                                                                      |
| `02-dashboard-readings.png`     | The dashboard with the four reading slots, some filled with their badges            |
| `03-add-reading-validation.png` | The add reading dialog showing a validation error (for example a value of 39)       |
| `04-daily-report.png`           | The Reports panel on the Daily tab, with the four stat cards and the day's readings |
| `05-month-to-date-chart.png`    | The Month to date tab with the line chart and the 70 and 180 reference lines        |
| `06-previous-month.png`         | The Previous month tab                                                              |
| `07-history-pagination.png`     | The History page with the pagination controls visible                               |
| `08-mobile.png`                 | A phone-width view (about 390 px wide) of the dashboard                             |

Use PNG, keep each file reasonably small (a few hundred KB), and do not include real personal data. The demo account is safe
to show.
